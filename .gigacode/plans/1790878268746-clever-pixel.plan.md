# План: Добавление кнопок загрузки/сохранения лабиринта + выбор двух клеток и решения

## Контекст

Проект модульный:
- **maze-core** — ядро (`MazeService`, `BfsSolver`, `Point`, `Maze`)
- **maze-desktop** — Swing UI (`DesktopApp`, `MazeController`, `ControlPanel`, `MazePanel`)

`BfsSolver.solve()` возвращает `List<Point>` — путь от start до end.
`MazeService.solve()` — фасад над солвером.

## Изменяемые файлы

| Файл | Действие |
|------|----------|
| `maze-desktop/.../desktop/ControlPanel.java` | Добавить кнопки "Load" и "Save" |
| `maze-desktop/.../desktop/MazePanel.java` | Добавить MouseListener для кликов; отрисовка зелёного пути |
| `maze-desktop/.../desktop/MazeController.java` | Подключить логику: обработка кликов, solve, load, save |
| `maze-desktop/.../desktop/DesktopApp.java` | Без изменений |

## Детали реализации

### 2. MazePanel — обработка кликов и отрисовка пути

**Состояние:**
```java
private Point startCell;     // null или первая выбранная клетка
private Point endCell;       // null или вторая выбранная клетка
private List<Point> solutionPath; // null или найденный путь
```

**MouseListener:**
- При клике на клетку (r, c) → переводим пиксели в row/col
- Если `startCell == null` → `startCell = new Point(r, c)`
- Иначе если `endCell == null` → `endCell = new Point(r, c)`
- Если обе выбраны → `startCell = new Point(r, c)`, `endCell = null` (сброс первой клетки, ожидание новой пары)
- После каждого клика → обновить `statusLabel` через `MazeController`
- Вызвать `repaint()`

**Отрисовка пути в `paintComponent`:**
- После отрисовки стен, если `solutionPath != null && !solutionPath.isEmpty()`:
```java
g2.setColor(new Color(0, 180, 0)); // зелёный
g2.setStroke(new BasicStroke(2));
for (int i = 0; i < solutionPath.size() - 1; i++) {
    Point p1 = solutionPath.get(i);
    Point p2 = solutionPath.get(i + 1);
    double x1 = p1.col() * cellW + cellW / 2;
    double y1 = p1.row() * cellH + cellH / 2;
    double x2 = p2.col() * cellW + cellW / 2;
    double y2 = p2.row() * cellH + cellH / 2;
    g2.drawLine((int) x1, (int) y1, (int) x2, (int) y2);
}
```

**Геттеры/сеттеры для UI-состояния:**
- `getStartCell()`, `getEndCell()`
- `setSolutionPath(List<Point> path)` — вызывает `repaint()`

### 3. MazeController — связывание логики

**Обработчик кликов (через MazePanel):**
- `MazePanel` вызывает callback или публикует событие при клике
- Controller обновляет `startCell`/`endCell` и `statusLabel`
- Если обе клетки выбраны — подсветить их (опционально)

**Обработчик кнопки "Solve":**
```java
private void onSolve() {
    Point start = mazePanel.getStartCell();
    Point end = mazePanel.getEndCell();
    if (start == null || end == null) {
        showError("Выберите две клетки кликом.");
        return;
    }
    List<Point> path = service.solve(mazePanel.getMaze(), start, end);
    if (path.isEmpty()) {
        showError("Путь не найден.");
        return;
    }
    mazePanel.setSolutionPath(path);
}
```

**Связывание:**
```java
private void wireListeners() {
    controlPanel.getGenerateButton().addActionListener(e -> onGenerate());
    controlPanel.getSolveButton().addActionListener(e -> onSolve());
    mazePanel.addCellClickListener(this::onCellClick);
}

private void onCellClick(Point cell) {
    if (startCell == null) {
        startCell = cell;
    } else if (endCell == null) {
        endCell = cell;
    } else {
        startCell = cell;
        endCell = null;
    }
    updateStatusLabel();
}

private void updateStatusLabel() {
    String text = "Клетки: ";
    if (startCell != null) text += "(" + startCell.row() + "," + startCell.col() + ")";
    if (endCell != null) text += " -> (" + endCell.row() + "," + endCell.col() + ")";
    controlPanel.getStatusLabel().setText(text);
}
```

### 4. MazePanel — интеграция кликов с Controller

Добавить в `MazePanel`:
```java
private Consumer<Point> cellClickHandler;

public void setCellClickHandler(Consumer<Point> handler) {
    this.cellClickHandler = handler;
}

@Override
public void mouseClicked(MouseEvent e) {
    int c = (int) (e.getX() / cellW);
    int r = (int) (e.getY() / cellH);
    if (inBounds(r, c) && cellClickHandler != null) {
        cellClickHandler.accept(new Point(r, c));
    }
}
```

В `MazeController`:
```java
mazePanel.setCellClickHandler(cell -> {
    // ... логика выше
    mazePanel.repaint();
});
```

### 5. MazeController — загрузка и сохранение

**Загрузка:**
```java
private void onLoad() {
    JFileChooser fileChooser = new JFileChooser();
    fileChooser.setDialogTitle("Загрузить лабиринт");
    int result = fileChooser.showOpenDialog(mazePanel);
    if (result == JFileChooser.APPROVE_OPTION) {
        try {
            Path path = fileChooser.getSelectedFile().toPath();
            Maze maze = service.load(path);
            mazePanel.setMaze(maze);
            mazePanel.setStartCell(null);
            mazePanel.setEndCell(null);
            mazePanel.setSolutionPath(null);
            updateStatusLabel();
        } catch (Exception e) {
            showError("Не удалось загрузить: " + e.getMessage());
        }
    }
}
```

**Сохранение:**
```java
private void onSave() {
    Maze maze = mazePanel.getMaze();
    if (maze == null) {
        showError("Сначала сгенерируйте или загрузите лабиринт.");
        return;
    }
    JFileChooser fileChooser = new JFileChooser();
    fileChooser.setDialogTitle("Сохранить лабиринт");
    fileChooser.setSelectedFile(new java.io.File("maze.txt"));
    int result = fileChooser.showSaveDialog(mazePanel);
    if (result == JFileChooser.APPROVE_OPTION) {
        try {
            Path path = fileChooser.getSelectedFile().toPath();
            service.save(maze, path);
        } catch (Exception e) {
            showError("Не удалось сохранить: " + e.getMessage());
        }
    }
}
```

**Wire:**
```java
private void wireListeners() {
    controlPanel.getGenerateButton().addActionListener(e -> onGenerate());
    controlPanel.getSolveButton().addActionListener(e -> onSolve());
    controlPanel.getLoadButton().addActionListener(e -> onLoad());
    controlPanel.getSaveButton().addActionListener(e -> onSave());
    mazePanel.setCellClickHandler(this::onCellClick);
}
```

## Верификация

1. Запустить `DesktopApp.main()`
2. Нажать "Generate" — лабиринт отрисовался
3. Кликнуть на клетку (0,0) — в статус-баре появилось "(0,0)"
4. Кликнуть на клетку (5,5) — статус: "(0,0) -> (5,5)"
5. Нажать "Solve" — зелёная линия толщиной 2px провела путь от (0,0) до (5,5)
6. Кликнуть ещё раз — сброс первой клетки, ожидание новой
7. Нажать "Save" — выбрать файл, лабиринт сохранён
8. Нажать "Load" — выбрать файл, лабиринт загружен
