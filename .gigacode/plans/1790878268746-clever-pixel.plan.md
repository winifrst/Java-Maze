# План: Исправить генерацию лабиринта по кнопке Generate

## Проблема

В `MazePanel.setMaze()` устанавливается новый лабиринт, но **не вызывается `repaint()`**.
Панель не перерисовывается, поэтому пользователь видит старое содержимое (или тестовый лабиринт).

## Файлы для изменения

| Файл | Действие |
|------|----------|
| `JavaMaze/maze-desktop/src/main/java/com/winifrst/maze/desktop/MazePanel.java` | Добавить `repaint()` в `setMaze()` |

## Решение

В `MazePanel.setMaze()`:

```java
public void setMaze(Maze maze) {
    this.maze = maze;
    repaint(); // ← добавить
}
```

## Верификация

Запустить `DesktopApp.main()` и нажать "Generate" — лабиринт должен отрисоваться.
